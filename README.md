# School-SW-Learning
**학교 소프트웨어 수업에서 진행한 다양한 실습 과제들을 모아 정리한 통합 레포지토리입니다.**
- 추가 설명:  
  백엔드 개발, 프론트엔드 개발, 데이터 분석, 딥러닝, Git 협업 실습 등 다양한 주제를 다루는 과제를 하나의 저장소로 통합하였습니다.  
  각 디렉토리는 독립된 프로젝트 단위로 구성되어 있으며, 실습 목적과 구현 방식에 따라 React, Spring Boot, Python, Jupyter Notebook 등 다양한 기술 스택을 활용했습니다.
---

## 📁 과제별 구성
| 폴더명 | 설명 |
|--------|------|
| `School-FS-Assign1-BoardApp/` | React + Express + MyBatis로 구현한 게시판 애플리케이션 |
| `School-DataProcessing/` | Pandas와 NumPy를 활용한 공공/상업 데이터 전처리 및 시각화 실습 |
| `School-DeepLearning/` | 단일 뉴런, 회귀, 분류 등 딥러닝 기초 실습 (Titanic, Dog vs Cat 등) |
| `School-Backend/` | Spring Boot 기반으로 구현한 게시판 백엔드 프로젝트 |
| `School-Git/` | Git 기본 명령어 및 협업 흐름 실습 통합 레포지토리 (하위에 2개 실습 포함) |
---
