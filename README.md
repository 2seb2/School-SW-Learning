# School-Git
**Git 기본 명령어부터 브랜치 전략과 협업 방식까지 실습한 Git 통합 과제 레포지토리입니다.**
- 추가 설명:  
  이 레포지토리는 Git의 기초 개념과 실무에서의 활용 방식을 단계적으로 학습하기 위해 구성되었습니다.  
  Python 스크립트를 활용한 Git 명령어 실습부터, Java 기반 Spring Boot 프로젝트에서 브랜치 생성, 병합, 충돌 해결 등 협업 중심의 Git 워크플로우까지 연습할 수 있도록 구성되어 있습니다.

## 📁 폴더 구성
| 폴더명 | 내용 |
|--------|------|
| `School-Git-Exam` | Git의 commit, branch, merge 등 기본 명령어를 Python 파일과 함께 실습 |
| `School-Git-Exam2` | 브랜치 전략, 충돌 해결 등 실무 Git 협업 흐름을 Spring Boot 프로젝트로 실습 |
